# Network Database Server

Многопоточный сетевой сервер базы данных с поддержкой различных структур данных и автоматическим сохранением в JSON формате.

## Описание

Этот проект представляет собой высокопроизводительный сетевой сервер базы данных, написанный на C++17. Сервер поддерживает множество структур данных и обеспечивает потокобезопасность при работе с несколькими клиентами одновременно.

## Особенности

- **Многопоточность**: Обработка множественных клиентских подключений с использованием пула потоков
- **Потокобезопасность**: Все операции с базой данных защищены мьютексами
- **Автосохранение**: Автоматическое сохранение изменений в JSON файл после каждой операции записи
- **Множественные структуры данных**: Поддержка множеств, стеков, очередей, хеш-таблиц и бинарных деревьев
- **Логирование**: Подробное логирование всех операций и подключений клиентов
- **Интерактивный режим**: Возможность выполнения команд прямо в терминале сервера

## Поддерживаемые структуры данных

### 1. Множества (Sets)
- `SADD <name> <value>` - добавить элемент в множество
- `SREM <name> <value>` - удалить элемент из множества
- `SISMEMBER <name> <value>` - проверить наличие элемента в множестве

### 2. Стеки (Stacks)
- `SPUSH <name> <value>` - добавить элемент на вершину стека
- `SPOP <name>` - извлечь элемент с вершины стека

### 3. Очереди (Queues)
- `QPUSH <name> <value>` - добавить элемент в конец очереди
- `QPOP <name>` - извлечь элемент из начала очереди

### 4. Хеш-таблицы (Hash Tables)
- `HSET <name> <key> <value>` - установить значение по ключу
- `HGET <name> <key>` - получить значение по ключу
- `HDEL <name> <key>` - удалить ключ и значение

### 5. Бинарные деревья (Binary Trees)
- `TINSERT <name> <value>` - вставить элемент в дерево
- `TFIND <name> <value>` - найти элемент в дереве (возвращает путь и позицию)

## Установка и сборка

### Требования
- C++17 совместимый компилятор (clang++ или g++)
- Make
- nlohmann/json библиотека (включена в проект)

### Сборка
```bash
# Сборка проекта
make

# Очистка объектных файлов
make clean

# Пересборка
make rebuild
```

## Использование

### Режим сетевого сервера
```bash
# Запуск сервера на порту по умолчанию (6379)
./program --server --file data/db.json

# Запуск сервера на кастомном порту
./program --server --file data/db.json --port 8080
```

### CLI режим (одиночные команды)
```bash
# Выполнение одной команды
./program --file data/db.json --query "SADD myset value1"
```

### Подключение к серверу
Используйте любой TCP клиент, например `nc` (netcat):
```bash
# Подключение к серверу
nc 127.0.0.1 6379

# Примеры команд
SADD test_set hello_world
HSET user:1 name "John Doe"
SPUSH my_stack item1
```

## Логирование

Сервер ведет подробные логи в файле `server.log`:
- Подключения и отключения клиентов
- Выполненные команды и их результаты
- Операции сохранения/загрузки базы данных
- Ошибки и предупреждения

## Безопасность и производительность

- **Потокобезопасность**: Все операции защищены мьютексами
- **Автоматическое сохранение**: Изменения сохраняются после каждой операции записи
- **Обработка ошибок**: Корректная обработка сетевых ошибок и исключений
- **Graceful shutdown**: Корректное завершение работы по сигналам SIGINT/SIGTERM

## Тестирование

Для тестирования многопоточности можно использовать параллельные подключения:
```bash
# Параллельное выполнение команд
for i in {1..5}; do
    echo "SADD parallel_set value_$i" | nc 127.0.0.1 6379 &
done
wait
```
